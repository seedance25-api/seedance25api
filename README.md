# Seedance 2.5 API — from $0.0874/s (480p)

**ByteDance Seedance 2.5 is live on [ArgoLink](https://argolink.io/en/models/seedance-2.5): $0.0874/s at 480p, $0.196/s at 720p, $0.483/s at 1080p, 15% below the BytePlus list price.**
A prompt plus optional images, video clips and audio go in; a 4–30 second video with its own soundtrack comes out.
One async REST API, billed per second, nothing charged for failed jobs, up to 50 jobs at the same time on each account.

- **BytePlus prices tokens, not seconds.** It lists $10.70 per million tokens at 480p and 720p and $11.70 at 1080p. One second of 16:9 video is 9,607.5 tokens at 480p, 21,600 at 720p and 48,600 at 1080p, which gives the per-second figures in the table.
- **A reference video changes the comparison.** ArgoLink adds the clip's seconds to the billed seconds at the same rate. Prompts, images and audio don't change the bill.

## Quick start

Create a key in the [ArgoLink console](https://argolink.io/app/keys), then export it:

```bash
export SEEDANCE_API_KEY=your-key
```

### cURL

```bash
# 1. Submit: the reply contains request_id
curl https://argolink.io/v1/videos/generations \
  -H "Authorization: Bearer $SEEDANCE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedance-2.5",
    "prompt": "A paper boat drifts down a rain-filled gutter, low camera following it, neon signs reflected in the water",
    "duration": 6,
    "resolution": "720p",
    "aspect_ratio": "16:9"
  }'

# 2. Poll (free) until status is done, failed or expired; pending jobs report progress 0-99
curl https://argolink.io/v1/videos/$REQUEST_ID \
  -H "Authorization: Bearer $SEEDANCE_API_KEY"

# 3. Fetch the MP4 (409 job_video_not_ready until done, 424 job_failed if it failed)
curl -L https://argolink.io/v1/videos/$REQUEST_ID/content \
  -H "Authorization: Bearer $SEEDANCE_API_KEY" -o boat.mp4
```

### Python

```python
import os, time, requests

API = "https://argolink.io/v1"
HEADERS = {"Authorization": f"Bearer {os.environ['SEEDANCE_API_KEY']}"}

job = requests.post(f"{API}/videos/generations", headers=HEADERS, json={
    "model": "seedance-2.5",
    "prompt": "A street musician plays saxophone under a bridge at dusk, slow dolly in",
    "duration": 8,
    "resolution": "720p",
    "aspect_ratio": "9:16",
}, timeout=60)
job.raise_for_status()
request_id = job.json()["request_id"]

while True:
    state = requests.get(f"{API}/videos/{request_id}", headers=HEADERS, timeout=60).json()
    if state["status"] == "done":
        break
    if state["status"] in ("failed", "expired"):
        raise RuntimeError(state)
    time.sleep(10)

clip = requests.get(f"{API}/videos/{request_id}/content", headers=HEADERS, timeout=600)
clip.raise_for_status()
with open("saxophone.mp4", "wb") as out:
    out.write(clip.content)
print(state["usage"])  # output_seconds, reference_video_seconds, billed_seconds
```

### Node.js

Node 18 or later, saved as an `.mjs` file:

```js
import { writeFile } from "node:fs/promises";

const API = "https://argolink.io/v1";
const headers = {
  Authorization: `Bearer ${process.env.SEEDANCE_API_KEY}`,
  "Content-Type": "application/json",
};

const { request_id } = await fetch(`${API}/videos/generations`, {
  method: "POST",
  headers,
  body: JSON.stringify({
    model: "seedance-2.5",
    prompt: "Close-up of rain on a window, focus pulls to the city skyline behind it",
    duration: 5,
    resolution: "1080p",
  }),
}).then((r) => r.json());

let job;
do {
  await new Promise((r) => setTimeout(r, 10_000));
  job = await fetch(`${API}/videos/${request_id}`, { headers }).then((r) => r.json());
} while (job.status === "pending");

if (job.status !== "done") throw new Error(`${request_id} ended as ${job.status}`);
const mp4 = await fetch(`${API}/videos/${request_id}/content`, { headers });
await writeFile("rain.mp4", Buffer.from(await mp4.arrayBuffer()));
```

Assets on your disk go up first. Ask for an upload ticket (free, it creates no job), `PUT` the file to `upload_url` within 15 minutes with the `Content-Type` you declared, and put the returned `media_url` in the request. It stays readable for seven days.

```bash
curl https://argolink.io/v1/media/uploads \
  -H "Authorization: Bearer $SEEDANCE_API_KEY" -H "Content-Type: application/json" \
  -d '{"model": "seedance-2.5", "type": "video", "content_type": "video/mp4", "size_bytes": 4821337}'
# → {"upload_url": "...", "media_url": "..."}
```

## Picking a mode

No `mode` field exists. The fields in the request decide what you get:

| You send | You get |
|---|---|
| `prompt` only | Text to video; missing fields default to 5 s, 720p, 16:9 |
| `prompt` + `start_image` | A video that opens on that frame (`aspect_ratio` is `adaptive` or left out) |
| `prompt` + `start_image` + `end_image` | The motion between two frames |
| `prompt` + `reference_images` / `reference_videos` / `reference_audios` | A clip that follows their subject, motion or beat; name them in the prompt as `@Image 1`, `@Video 1`, `@Audio 1`. Audio alone works |
| `prompt` + `omni_reference_task_type: "edit"` + `reference_videos[0]` | An edit of that 4–30 s clip, keeping its length and ratio |

Frame fields can't be combined with reference assets. `size` (for example `1280x720`) can replace `resolution` plus `aspect_ratio`. Requests written for fal or OpenRouter keep working: `image_url`, `image_urls`, `video_urls` and `audio_urls` are accepted. `seed`, `watermark: true` and `n` above 1 are rejected with 400. Every field is listed in the [API reference](https://argolink.io/en/models/seedance-2.5#model-panel-api).

## Billing rules worth knowing

1. **You pay per second of output**, at the rate of the resolution you chose.
2. **Reference video seconds are added.** A 5 s result with a 3 s reference clip bills 8 s. Reference images and audio are free.
3. **An edit bills twice its length**, because the clip counts as output and as reference: editing 5 s bills 10 s.
4. **Failed, rejected and expired jobs cost nothing.** An asset outside the limits (images ≤ 20 MiB, videos ≤ 100 MiB, audio ≤ 15 MB, clips 2–30 s) fails with `invalid_input` before generation starts.
5. **The finished job tells you the bill**: `usage` holds `output_seconds`, `reference_video_seconds` and `billed_seconds`.

## FAQ

**Can I call Seedance 2.5 from outside China?**
Yes. Sign up at argolink.io and use a regular API key from any country. You don't need a BytePlus or Volcengine account.

**Seedance 2.5 or Seedance 2.0?**
2.5 renders longer clips (4–30 s against 4–15 s), takes more references (30 images, 10 videos and 10 audio clips against 9 / 3 / 3) and is the Seedance model that edits existing footage. [Seedance 2.0](https://argolink.io/en/models/seedance-2.0) costs less, from $0.053/s at 480p, and is the one that outputs 4K. Both take the same request body, so you switch by changing `model`.

**How many videos can I generate in parallel?**
Up to 50 Seedance 2.5 jobs per account, whatever the account has spent. Past that the API answers `429 rate_limit_error`; if no capacity is free it answers `503` with a `Retry-After` header. Both are safe to retry.

**How do I know how long a job has left?**
While a job is `pending`, the status call returns `progress` (0–99) and, once it has one, `estimated_seconds_remaining`.

**Can I try it before writing code?**
Yes. The [playground](https://argolink.io/app/playground?model=seedance-2.5) has the same parameters after you sign in.
